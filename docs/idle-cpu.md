# Простой панели

Живой замер контейнера на Mac в этом прогоне не делался: `not_run`. Здесь нет Docker и это не Mac mini. Метод, когда панель крутится на том Mac: открыть обзор `http://127.0.0.1:4317`, не ставить задачи и не запускать игру, подождать 30 секунд и десять раз снять `docker stats --no-stream` у контейнера панели. В отчёт писать среднее CPU%. Рядом смотреть, что Docker Desktop не крутит `diskutil` и обход дисков.

Ниже не проценты CPU, а число пробуждений в минуту по коду `ca1059a` (страница открыта, очередь пустая). После правки рабочие таймеры в простое — 0. Комментарий SSE очереди раз в 15 секунд остаётся, пока вкладка держит поток: это не опрос диска. Если агент ПК недоступен, панель ждёт 30 секунд и снова открывает один поток событий, без опроса дисков.

| Источник | Было, пробуждений/мин | Стало |
| --- | --- | --- |
| Планировщик при старте | 6 | 0, пока нет активной или стоящей в очереди загрузки |
| Авторазмещение | 5 | 0 в простое |
| Анонс LocalSend | 6 | один анонс при сокете, без повтора |
| Два воркера очереди | 300 | 0, пока нет задачи |
| Быстрый опрос страницы | 12 | 0 |
| Тяжёлый опрос страницы | 1 | 0 |
| Сумма | 330 | 0 |

Числа зафиксированы в `src/lib/idle/budget.ts`. Страница обновляется при открытии, переходе и событии очереди. Скрытая вкладка не запрашивает данные. Диски Mac: DiskArbitration и FSEvents на хосте, один `diskutil info <точка>` на новое монтирование, без таймера и без `fs.watch`.

## Замер владельца на Mac

Это не замер этого прогона. Панель в среднем 4.8% ядра, пики 30%. `com.docker.backend` в среднем 10.6%. Процесс drive-agent pid 41335 в 9 из 12 проб вызывал `diskutil info -all`.

Этот процесс — код отката `d6a6d57`: `agents/lib/agent.mts` ставит `setInterval` на 4 секунды, а `agents/mac-agent/collect.mts` каждый раз запускает `diskutil info -all`. Смерженный #21 (`a89261dd94af9ee8f05f995a9b3fe72daeac60a9`) этот цикл уже снял: `tick()` один раз при старте, `diskutil info` только для одной точки монтирования и только при появлении тома. В #24 `assertSpawnAllowed` отклоняет `info -all`, а тест `src/lib/idle/idle.test.ts` читает исходники агента и требует отсутствия `"-all"` и `setInterval`. Пока pid 41335 не перезапущен из этого дерева, он продолжает старый цикл. Перезапуск:

```bash
node --import ./agents/register.mjs agents/mac-agent/drive.mts --port 4371
```
