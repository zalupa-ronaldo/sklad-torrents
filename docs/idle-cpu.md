# Простой панели

Живой замер контейнера на Mac в этом прогоне не делался: `not_run`. Здесь нет Docker и это не Mac mini. Метод, когда панель крутится на том Mac: открыть обзор `http://127.0.0.1:4317`, не ставить задачи и не запускать игру, подождать 30 секунд и десять раз снять `docker stats --no-stream` у контейнера панели. В отчёт писать среднее CPU%. Рядом смотреть, что Docker Desktop не крутит `diskutil` и обход дисков.

Ниже не проценты CPU, а число пробуждений в минуту по коду `ca1059a` (страница открыта, очередь пустая). После правки рабочие таймеры в простое — 0. Комментарий SSE очереди раз в 15 секунд остаётся, пока вкладка держит поток: это не опрос диска. Если агент ПК недоступен, панель ждёт 30 секунд и снова открывает один поток событий, без опроса дисков.

| Источник | Было, пробуждений/мин | Стало |
| --- | --- | --- |
| Планировщик при старте | 6 | 0, пока нет активной или стоящей в очереди загрузки |
| Авторазмещение | 5 | 0 в простое |
| Анонс LocalSend | 6 | один анонс при сокете, без повтора |
| Два воркера очереди | 300 | 0, пока нет задачи |
| Быстрый опрос страницы | 12 | 0 |
| Тяжёлый опрос страницы | 1 | 0 |
| Сумма | 330 | 0 |

Числа зафиксированы в `src/lib/idle/budget.ts`. Страница обновляется при открытии, переходе и событии очереди. Скрытая вкладка не запрашивает данные. Диски Mac: DiskArbitration и FSEvents на хосте, один `diskutil info` на новое монтирование, без таймера и без `fs.watch`.
