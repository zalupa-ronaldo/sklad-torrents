# Склад — спецификация продукта

Одна панель на Next.js для домашней сети. Она не заменяет qBittorrent и не содержит своего BitTorrent-движка. VLESS и прокси нет.

## Архитектура

Один процесс `npm run dev` (порт 4317) и общие данные в `data/`.

Модули ходят в одно ядро:

- **Хосты qBittorrent.** Несколько Web UI (Mac mini, Windows). Вход, список, магнет и `.torrent`, пауза, продолжение, удаление, каталог сохранения, `setLocation`, приоритет файла. Единый список: хост, состояние, прогресс, путь, размер, раздача или загрузка. Поиск по имени.
- **Каталог дисков.** Серийный номер, UUID тома, файловая система, подпись, объём на последнем скане, дерево, что там лежит, когда диск видели и на каком хосте. Полка ищет и отключённые диски.
- **Очередь заданий.** Перенос, копирование, индексация, сжатие, HandBrake, оптика, LocalSend. Состояния: в очереди, выполняется, пауза, готово, ошибка. Запрос только ставит задачу и сразу отвечает. Прогресс — SSE, опрос если поток оборвался. Очередь на диске переживает перезапуск. Повтор ограничен и не удаляет источник. Один и тот же источник, назначение, вид и хост не создают вторую активную задачу. Mac и Windows забирают задачи отдельно, одну задачу дважды не берут.
- **Планировщик загрузок.** Не больше одной активной загрузки на физический диск. Диски независимы. Раздача готовых торрентов не ограничена. Отключённый диск ждёт. Очередь можно переставить, «следующим» не запускает вторую загрузку на том же диске. Два хоста с одним серийным номером и UUID делят слот. Если каталог путь не узнал, слот временный: хост и корень тома (`/Volumes/<имя>` или буква диска Windows). Это не личность диска.
- **Правила контента.** Типы: игры (ПК, консоль, PSP, другое), фильмы, сериалы, музыка, софт, документы, прочее. Сначала ручной тип, потом имя и расширения. Размер сам по себе игру не означает. У типа — диск и папка, профиль индекса, действие после: ничего, сжатие NTFS или HandBrake. Автоматика по умолчанию выключена. Включить её можно только после свежего сухого прогона. Устаревший прогон включение блокирует. Прогон ничего не удаляет.

Инструменты медиа и игр, полка, оптика и LocalSend — экраны этого же приложения, не отдельные продукты.

## Личность диска и индекс

Совпадение только по серийному номеру и UUID тома. Буква и точка монтирования личность не задают. Тот же диск в другом порту — та же запись. Тот же UUID и другой серийник — клон, записи не сливаются. Две точки монтирования одной пары — один диск.

Подключение на Mac или Windows само находит том и ставит фоновую индексацию. Индексация только читает. Она не форматирует, не чинит, не меняет букву, не сжимает и не переносит файлы. Ошибка чтения не помечает файлы удалёнными, пока полный повторный обход не завершился успешно. При сильной нагрузке на диск обход встаёт на паузу и потом продолжается.

NTFS на Windows: MFT (Master File Table) и журнал USN, как Everything. Сырой том читается только от администратора. Без прав — обычный обход папок. APFS, HFS, exFAT и `/Volumes/vault` — только обход. MFT и сжатие на APFS и на `/Volumes/vault` не запускаются.

Поиск по полке включает отключённые диски. В ответе подпись диска и путь. Если диск на полке, сказано, какой именно подключить.

## Перенос, сжатие, HandBrake

Готовая раздача переезжает через `setLocation` на том же хосте, раздача не снимается.

HandBrakeCLI настраивается путём на Mac и на Windows. Бинарник в репозиторий не кладётся. Задание пишет отдельный выходной файл.

CompactGUI / `compact.exe` — только NTFS на Windows: LZX, XPRESS8K, XPRESS16K, XPRESS4K. На Mac пункт недоступен. Оценка экономии показывается, когда её сообщил исполнитель.

Перенос игры с HDD на SSD: выбрать источник и назначение, скопировать, проверить. Сжать назначение можно, если это NTFS. Запись в библиотеке обновляется. Исходник не удаляется, пока копия не проверена и человек отдельно не подтвердил удаление. Отмена задания файлы не стирает. Пауза есть только если исполнитель её умеет; иначе интерфейс прямо пишет об этом по-русски.

У раздачи со всеми файлами на 100% в карточке есть ссылки на HandBrake и на перенос. В общей таблице раздач этих инструментов нет.

Списки дисков, файлов и заданий листаются страницами.

## Противоречия, которые уже сняты

- Дополнения — модули одного приложения, не отдельные продукты и не вторые очереди «для себя». Общая очередь, общий каталог, общий планировщик.
- MFT — Master File Table. Написания MTF в продукте нет.
- Сжатие, перенос, перекодирование и индекс — задания. Они не выполняются внутри HTTP-запроса и не стартуют сами от того, что диск воткнули. От подключения ставится только чтение индекса.
- Одна активная загрузка — на физический диск, не на хост qBittorrent. Раздача не лимитируется.
- Отключённый диск остаётся в каталоге и в поиске.
- Автоматика выключена, пока нет свежего сухого прогона.
- µTorrent вне продукта. Своего торрент-движка нет.
- Одинаковый UUID при другом серийнике — клон, не слияние.
- Удаление исходника не входит в индекс, повтор, отмену и включение автоматики.

## Что работает сейчас и что позже

Сейчас, в том числе в облаке, где нет настоящих дисков, HandBrake и NTFS:

- панель, демо-хосты qBittorrent, поддельный Web API в тестах;
- полка с демо-дисками и поиском, включая отключённый диск;
- планировщик одной загрузки на диск на демо-раздачах;
- правила, сухой прогон и постановка заданий без удаления;
- очередь с прогрессом; демо-исполнители не запускают HandBrake и `compact.exe`;
- синтетический разбор MFT и USN на буферах в тестах, не на томе;
- агент Windows (`node agents/pc-agent/server.mjs`) по умолчанию в макете;
- агент Mac в процессе — `startMacAgent` в `agents/mac-agent/index.ts`, тоже макет очереди.

Позже, на живой сети и только руками:

- чтение настоящего тома NTFS от администратора и инкремент USN на железе;
- вызов HandBrakeCLI и `compact.exe` агентом (`SKLAD_PC_AGENT_MOCK=0` и пути к программам);
- живая запись оптики агентом Windows. В этом репозитории облако диск не прожигает.

## Как запустить

```bash
npm install
npm test
npm run dev
```

Панель: http://127.0.0.1:4317

Агент Windows, макет: `npm run pc-agent` или `node agents/pc-agent/server.mjs`. Подробности — `agents/pc-agent/README.md`.

qBittorrent, HandBrake, CompactGUI и права администратора для MFT ставятся отдельно. Их пути задаются в панели. Пароли Web UI лежат в `data/` и в git не попадают.
