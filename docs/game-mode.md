# Игровой режим

Когда на Windows идёт игра, Склад мягко ставит на паузу фон этого ПК и продолжает его, когда игра закрылась. Процессы не завершаются. Прогресс не сбрасывается. Steam и его процессы (`steam.exe`, `steamwebhelper.exe` и остальные из списка в `src/lib/game-mode/steam.ts`) не получают сигналов. Имя вроде `SteamWorldDig.exe` в этот список не входит.

## Как узнаёт

Агент ПК (`SKLAD_PC_AGENT_MOCK=0`, только Windows) один раз читает `libraryfolders.vdf`, если файл есть, и дальше слушает `Win32_ProcessStartTrace` / `Win32_ProcessStopTrace`. Это события, не опрос. Полноэкранное окно переднего плана отмечается в том же событии. Библиотека Склада передаётся так:

```json
POST /v1/game-mode/library
{ "entries": [{ "name": "Hades", "exe": "Hades.exe", "source": "sklad" }] }
```

Ручной переключатель: `POST /v1/game-mode` и `POST /api/game-mode` с `{ "mode": "on" | "off" | "auto" }`. `on` ставит паузу без процесса. `off` не даёт авторежиму сработать, пока его не вернут в `auto`. Состояние видно в шапке панели и на полке игр. Поток: `GET /api/game-mode/events` и `GET /v1/game-mode/events`.

## Что встаёт на паузу

- Загрузки qBittorrent на Windows-хосте, через Web API. Раздача и пауза, которую поставил человек, не снимаются этим режимом: продолжаются только хеши, которые поставил он.
- Кодирование AV1: `HandBrakeCLI.exe` и соседние кодировщики из `detect.ts`. `Suspend-Process` / `SIGSTOP`, затем `Resume-Process` / `SIGCONT`.
- NSZ: процесс `nsz.exe`.
- CompactGUI и `compact.exe`.

Очередь агента с `gameHeld` не берёт новую тяжёлую задачу. `SIGKILL`, `taskkill` и `Stop-Process` для этого режима не вызываются. В mock (`SKLAD_PC_AGENT_MOCK` не `0`) план считается, процессы не запускаются.

Если агент или панель оборвались, пока фон был заморожен, старт снимает эту заморозку: `Resume-Process` по записанным pid и продолжение тех раздач, чьи хеши лежат в `game-mode-hold.json`. Игра, которая всё ещё идёт, ставит паузу снова по событию. Так зависший процесс не остаётся остановленным навсегда.

Идея паузы фона на время игры — у клиента Steam и у Playnite. Их код сюда не копировался.
