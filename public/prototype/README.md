# Панель коллекции

`http://127.0.0.1:4317/` открывает эти экраны на живых ответах API. `demo-data.js` используется только при `npm run dev` и `?demo=1`. Очередь задач читает ход AV1 через `GET /api/tools/av1-status` и не запускает кодирование. Задачи и прогресс обновляются раз в 5 секунд. Диски, устройства и AV1 — при открытии раздела или раз в минуту. Скрытая вкладка опрос останавливает. Удаление, сброс, запись диска, правила раскладки и отмена задачи сначала спрашивают подтверждение. «Сжать каталог» вызывает `POST /api/drives/compact`, «Переименовать диск» — `PATCH /api/drives/:id`. Полка игр читает `platforms[].games` и не придумывает названия. Если ответ помечен `showingSamples`, эти примеры на живой полке не показываются.

Дальше — описание демо-сценариев, если открыт `?demo=1`.

- **Устройства** в боковом меню показывает носители по хостам, занятое и свободное место, доступность и время последнего скана. Отключённый носитель можно открыть в каталоге по сохранённому снимку.
- **Очередь задач** в боковом меню показывает копирование и автоматическое перекодирование в AV1. У активной задачи есть скорость, оставшееся время, пауза и отмена. Задачу с ошибкой можно повторить.
- **Детали файла** открываются нажатием на имя в разделе «Все файлы». У `Sintel.mkv` можно посмотреть дорожки и SHA-256, переключиться между копиями и выбрать назначение. Для примера выберите «Камера SD», чтобы увидеть нехватку места, или «Vault SSD», чтобы поставить копирование в очередь.

Переключатель **«Демо»** в верхней панели действует на текущий экран и сбрасывает изменения в снимке.

| Сценарий | Что посмотреть |
| --- | --- |
| Норма (`normal`) | Запустите сканирование или скопируйте файл. |
| ПК офлайн (`offline`) | Каталог Windows доступен по последнему снимку. Для копирования можно выбрать экземпляр на флешке. |
| Идёт копирование (`copying`) | Откройте очередь, чтобы приостановить копирование или задачу AV1. |
| Ошибка (`error`) | Откройте ошибку сканирования флешки либо повторите копирование или перекодирование. |
| Пусто (`empty`) | В снимке нет устройств, файлов и задач. |
| Загрузка (`loading`) | На месте содержимого видны скелетоны. |

Чтобы увидеть пустое состояние или загрузку деталей, сначала откройте файл, затем смените сценарий.

## Функция legacy → экран прототипа

В боковом меню сверху находятся хранилище, очередь и библиотека. Кнопка **«Ещё»** раскрывает обработку, сеть и оборудование. На телефоне меню открывается кнопкой слева от названия экрана.

| Функция legacy | Экран прототипа | Что проверить |
| --- | --- | --- |
| Хосты qBittorrent | Ещё → Хосты | Добавьте хост, измените адрес и проверьте связь. Сброс настроек и демораздач, а также удаление хоста требуют подтверждения. |
| Носители и файлы | Устройства → карточка диска | Пересканируйте носитель, выберите каталог NTFS для сжатия или скачайте демофайл. У отключённого диска доступен сохранённый каталог. |
| Управление раздачей | Торренты → название раздачи | Посмотрите info hash и SHA-256, скачайте манифест, откройте правило категории. При удалении выберите, что делать с файлами. |
| Перенос раздачи между хостами | Торренты → завершённая раздача → Перенести на другой хост | Выберите диск другого хоста. После успешной сверки раздача привязывается к копии. Исходник остаётся доступен до отдельного подтверждения. |
| Прогресс и целостность | Очередь задач → название задачи; Ещё → Проверка SHA-256 | В карточке видны скорость, ETA, контрольные суммы и лента событий. Пауза, продолжение и повтор отражаются в журнале. |
| Расписание и авторежим | Ещё → Планировщик | Задайте дни и окно запуска. Внутри окна демочасы запускают сканирование. В баннере текущего конвейера можно открыть выполняющуюся задачу. |
| LocalSend | Ещё → LocalSend | Обновите список устройств, выберите файл и получателя, проверьте историю передачи. В настройках меняются имя, порт, обнаружение и диск приёма. |
| Оптические носители | Ещё → Оптические диски | Соберите ISO, выберите образ для записи, откройте лоток и вставьте чистый носитель. Записанный диск появится в коллекции. |
| Правила раскладки | Ещё → Правила раскладки | Выберите категорию, укажите диск и папку, выполните пробный прогон. Применение создаёт задачи. Автоматика доступна после предпросмотра. |
| Игровая библиотека | Игровая полка | Отфильтруйте карточки с обложками по платформе, подготовьте копию на SSD и откройте подготовленную игру. |
| Индекс, SSD, NTFS и AV1 | Ещё → Медиа-инструменты | Выберите вкладку. У AV1 видны текущий файл, процент, fps, ETA, число готовых файлов и экономия объёма. Профиль кодировщика, алгоритм сжатия и пути инструментов задаются в настройках. |
| Копирование и перенос файлов | Перенос и копирование | Выберите исходный носитель, файл и цель. Форма проверит доступность, совпадение пути и свободное место. Подтверждение удаления исходника находится в деталях проверенной задачи. |

В сценарии **«Ошибка»** есть прерванные задания. Первая попытка выполнить действие на соответствующем экране показывает ошибку агента. Повтор позволяет проверить восстановление. В **«ПК офлайн»** продолжают работать операции между доступными носителями.

Скачиваемый файл содержит короткую демопоследовательность, для которой рассчитан показанный SHA-256. Размеры носителей и медиаданных, скорость и время обработки моделируются. Изменения сбрасываются при перезагрузке страницы или переключении сценария.
