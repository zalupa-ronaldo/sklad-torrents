# Панель коллекции

`http://127.0.0.1:4317/` открывает этот интерфейс. Данные живут в API панели. `?demo=1` оставляет сценарии только в `npm run dev`.

- **Устройства** — носители по хостам, занятое место и пересканирование.
- **Очередь задач** — копирование, задания панели и ход AV1. Журналы Windows только читаются. Если агент ПК не в сети, очередь так и пишет.
- **Детали файла** — путь, размер, копии и SHA-256, если панель его уже посчитала.

Прежний интерфейс: `/legacy`.
